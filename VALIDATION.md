# Проверка Product Metrics

## 0.3.0 - шесть навыков

Проверка выполнена 4 октября 2026 года на рабочей ветке перед выпуском.

### Что запускалось и прошло

| Проверка | Результат |
|---|---|
| `claude plugin validate . --strict` (корень репозитория) | прошла |
| `claude plugin validate plugins/product-metrics --strict` | прошла |
| `.venv/bin/python scripts/validate_package.py` | прошла: 6 навыков, 16 учебных карточек, 13 связей |
| `python3 plugins/product-metrics/scripts/render_system.py` на системах `beacon`, `shop`, `platform` | 0 ошибок |
| Проверка относительных ссылок между файлами | 0 битых |
| Текстовая проверка на запрещённые ссылки и обозначения | чисто |

Результаты eval-набора (4 октября 2026, `--runs 1 --ablation none --model sonnet --judge-model haiku --threshold 0.8`): 14 кейсов из 14 прошли на 1.0 после двух итераций. Первый полный прогон выявил ошибку формата фикстур (`scaffold_script` - путь к файлу внутри папки кейса) и слишком строгие грейдеры в четырёх кейсах; один реальный дефект - режим карты `metrics-system` срабатывал в 1 запуске из 3 на вопрос «из чего состоит WAU». После добавления триггерных фраз в описание кейс `system-map-wau` прошёл 3 из 3 запусков. Правило «отвечай на языке запроса» добавлено во все скиллы после того, как английский кейс подтвердил английский ответ. Оценки - одиночные запуски, LLM-грейдеры шумят; стоимость полного прогона около 2,5 долларов.

### Ограничения

- Проверены документы и учебные данные. Реальные данные организации не использовались.
- Поведение языковой модели измерено только набором `plugins/product-metrics/evals/`; других запусков на новых инструкциях не проводилось.
- Рендер Mermaid в клиенте не выполнялся: скрипт проверяет структуру и строит текст схемы.
- Установка 0.3.0 в Codex и Claude Code в этой записи не повторялась: [результаты 0.1.0 и 0.2.0](#020---расчёт-и-sql) относятся к прежним версиям.

## 0.2.0 - расчёт и SQL

Проверка выполнена 1 октября 2026 года. Новые запросы действительно исполнены в SQLite 3.52.0 на вымышленных подготовленных строках; [сохранённый результат](plugins/product-metrics/shared/examples/sql/verification.json) содержит параметры, оба результата и десять проверочных случаев.

Проверены доля и среднее, выбор месяца и продукта, завершение сценария в следующем месяце, граница зрелости, предварительный срез, пустая группа и отсутствие успехов. Ограничения учебной таблицы отклоняют дубли подготовленных сценариев, пропущенную, отрицательную и чрезмерную длительность успеха. Проверка подготовки сырых событий в этот результат не входит.

[Проверка пакета](scripts/validate_package.py) прошла: согласованные манифесты, четыре навыка, шесть карточек, ссылки и зависимости. Изменённые навыки `metric-catalog` и `metrics-review` прошли `skill-creator/quick_validate.py`; строгая проверка каталога и плагина Claude Code завершилась без предупреждений. Схема установки сохранена от предыдущего выпуска.

Для повторения выполните из корня репозитория:

```bash
python3 plugins/product-metrics/shared/examples/sql/run_examples.py
.venv/bin/python scripts/validate_package.py
claude plugin validate . --strict
claude plugin validate plugins/product-metrics --strict
```

Успешная проверка относится к документам и учебным запросам. Подготовка событий, полнота источников и реальные значения метрик организации не проверялись. Независимый запуск языковой модели на новых инструкциях не проводился.

## 0.1.0 - первоначальная установка

Проверка выполнена 1 октября 2026 года на Codex CLI 0.143.0 и Claude Code 2.1.283. Результат относится к упаковке плагина и учебным определениям.

### Что проверено

Пакет успешно установлен из локального источника в отдельные временные настройки обоих клиентов. Codex показывает его установленным и включённым. Claude Code показывает четыре навыка: `metrics-setup`, `metric-catalog`, `metrics-system`, `metrics-review`. Файлы в обоих кэшах совпали с исходниками; относительные ссылки навыков на общие материалы разрешаются внутри установленного пакета.

Строгая проверка Claude Code для каталога установки и плагина прошла без предупреждений. Четыре навыка прошли `skill-creator/quick_validate.py`. [Проверка пакета](scripts/validate_package.py) подтвердила согласованность манифестов, шесть учебных карточек, реестр, версии и шесть типизированных связей.

В отдельных копиях проверяющий скрипт обнаружил все три намеренно внесённые ошибки: устаревшую версию метрики у потребителя, цикл математического расчёта и отсутствующий общий шаблон. Исходные материалы при этих проверках не менялись.

### Как повторить

Установите зависимости проверки по README, выполните скрипт и штатный валидатор клиента. Для проверки установки используйте отдельный тестовый проект и отдельные настройки клиента, затем проверьте инвентарь компонентов и доступ к `shared/` из установленной копии.

```bash
.venv/bin/python scripts/validate_package.py
claude plugin validate . --strict
claude plugin validate plugins/product-metrics --strict
```

### Границы результата

Эти проверки подтверждают структуру и установку. Независимый запуск языковой модели на пользовательском запросе, реальные расчёты и пользовательский пилот не проводились. Экономия времени и расход контекста не измерены. Доступность конкретных команд установки зависит от версии клиента; навыки не гарантируют безошибочного решения аналитической задачи.
