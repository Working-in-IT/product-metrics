# Проверка версии 0.1.0

Проверка выполнена 1 октября 2026 года на Codex CLI 0.143.0 и Claude Code 2.1.283. Результат относится к упаковке плагина и учебным определениям.

## Что проверено

Пакет успешно установлен из локального источника в отдельные временные настройки обоих клиентов. Codex показывает его установленным и включённым. Claude Code показывает четыре навыка: `metrics-setup`, `metric-catalog`, `metrics-system`, `metrics-review`. Файлы в обоих кэшах совпали с исходниками; относительные ссылки навыков на общие материалы разрешаются внутри установленного пакета.

Строгая проверка Claude Code для каталога установки и плагина прошла без предупреждений. Четыре навыка прошли `skill-creator/quick_validate.py`. [Проверка пакета](scripts/validate_package.py) подтвердила согласованность манифестов, шесть учебных карточек, реестр, версии и шесть типизированных связей.

В отдельных копиях проверяющий скрипт обнаружил все три намеренно внесённые ошибки: устаревшую версию метрики у потребителя, цикл математического расчёта и отсутствующий общий шаблон. Исходные материалы при этих проверках не менялись.

## Как повторить

Установите зависимости проверки по README, выполните скрипт и штатный валидатор клиента. Для проверки установки используйте отдельный тестовый проект и отдельные настройки клиента, затем проверьте инвентарь компонентов и доступ к `shared/` из установленной копии.

```bash
.venv/bin/python scripts/validate_package.py
claude plugin validate . --strict
claude plugin validate plugins/product-metrics --strict
```

## Границы результата

Эти проверки подтверждают структуру и установку. Независимый запуск языковой модели на пользовательском запросе, реальные расчёты и пользовательский пилот не проводились. Экономия времени и расход контекста не измерены. Доступность конкретных команд установки зависит от версии клиента; навыки не гарантируют безошибочного решения аналитической задачи.
