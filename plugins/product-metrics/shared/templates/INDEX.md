# Реестр метрик

Это вход для поиска определений всех продуктов команды. Одна строка соответствует одному актуальному ключу; полное определение находится по ссылке в последней колонке.

| id | Продукт | Название | Синонимы | Версия | Статус | Формат | Определение |
|---|---|---|---|---|---|---|---|

Карточки пока не зарегистрированы. После первой записи удалите эту фразу. Для старых описаний используйте `legacy`; неизвестную версию или статус обозначайте `unknown`. Исторические версии и учебные примеры в рабочий реестр не добавляются.
