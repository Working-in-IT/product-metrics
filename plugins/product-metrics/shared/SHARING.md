# Передача и обновление Product Metrics

Для передачи другой команде отправьте ссылку на [репозиторий](https://github.com/Working-in-IT/product-metrics) или его выпуск. Получатель устанавливает плагин целиком: четыре навыка используют общую папку материалов.

## Что устанавливается

Пакет содержит инструкции, формат, шаблоны и вымышленные примеры. Одной папки навыка недостаточно: ссылки ведут в `shared/` внутри плагина. Для агента без системы плагинов можно сохранить весь пакет и указать путь к `skills/<name>/SKILL.md`.

Два небольших каталога установки — для Codex и Claude Code — показывают клиентам, где расположен один и тот же пакет. Они не содержат метрик пользователя.

## Где находятся собственные метрики

Рабочий `CATALOG.md`, реестр и карточки создаются в проекте организации. Пути и правила согласования задаются в профиле. Обновление плагина не заменяет эти файлы. Для командной работы предоставьте доступ к каталогу через привычный механизм своей базы знаний.

Если передаются реальные карточки, подготовьте отдельный набор: проверьте закрытые адреса, личные данные, значения, историю и вложения. Недоступный получателю источник обозначьте явно, не заменяя его вымышленным подтверждением расчёта.

## Как получать обновления

Перед обновлением прочитайте историю выпуска и проверьте совместимость `schema_version`. Версия плагина, версия формата и версия определения метрики независимы; обновление инструкций само по себе не меняет определение.

Для Codex, если источник закреплён на теге, замените регистрацию именно этого источника через `codex plugin marketplace remove working-in-it-metrics` и `codex plugin marketplace add Working-in-IT/product-metrics --ref <новый-тег>`, затем установите пакет через `codex plugin add product-metrics@working-in-it-metrics` или интерфейс клиента. Для источника, следующего ветке, используйте `codex plugin marketplace upgrade working-in-it-metrics` и обновите установку.

Для Claude Code выполните `claude plugin marketplace update working-in-it-metrics`, затем `claude plugin update product-metrics@working-in-it-metrics`. Начните новую сессию. Порядок описан в [документации клиента](https://code.claude.com/docs/en/plugin-marketplaces).

## Как адаптировать правила

Пути и продукты настраиваются через местный профиль. Для изменения самой методики можно создать собственный вариант репозитория. Несовместимое изменение формата получает новый `schema_version` и явный план миграции; обновление установки не мигрирует карточки автоматически.

Комплект распространяется по MIT; текст лицензии находится в корне репозитория. [Источники](references/SOURCES.md) приведены ссылками, чужие статьи и программные реализации в пакет не включены.
