# Средний чек - Shop

Учебная карточка вымышленного магазина Shop. Валюта не названа: числа даны в денежных единицах.

## Смысл и применение

Показывает среднюю сумму оплаченного заказа. Помогает заметить сдвиг состава заказов и не принять его за изменение каждого заказа.

## Определение и расчёт

`aov = revenue / orders`: [выручка](revenue.md) делится на [оплаченные заказы](orders.md) одного окна и одной версии определений. Единица наблюдения - заказ. Это отношение сумм. Для объединения непересекающихся групп (сегментов, недель) суммировать выручку и заказы отдельно, затем делить. Среднее из средних сегментов даёт неверный результат, как и вес по доле выручки: единица усреднения - заказ.

## Границы

Правила числителя и знаменателя - как в карточках компонентов. При `orders = 0` результат `null`, причина - нет заказов. При недоступных данных значение неизвестно с отдельной причиной. Сравнивать окна можно только при одинаковых правилах возвратов, доставки и налогов. [Сегмент заказа](order_segment.md) задан на момент заказа.

## Источник и проверка

Основание: арифметика отношения сумм на вымышленных данных; оговорка о составе - Sequoia Capital, "Analyzing Metric Changes Part V: Mix Shift", https://articles.sequoiacap.com/metrics-mix-shift (блог фонда, без года). Проверка реализации: `not_checked`.

### Как посчитать

Учебный вариант на файлах [aov-segments.csv](../../../data/aov-segments.csv) и [aov-weekly.csv](../../../data/aov-weekly.csv). Окно A: 67900 / 1000 = 67.9. Окно B: 61700 / 1000 = 61.7. Недельный ряд хранит только `aov`; заказы и выручка известны лишь для w8, остальные ячейки пусты (неизвестно). Проверка ручная.

## Интерпретация

Внутри обоих сегментов средний чек вырос (85 → 86 и 28 → 32), общий упал на 6.2: доля Premium по заказам снизилась с 70% до 55%. Разложение в названном порядке (сначала веса при старых средних, затем средние при новых весах): структура -8.55, средние +2.35, сумма -6.2. Другой порядок даст другие слагаемые с той же суммой. Это бухгалтерия изменения, не причина.

Недельный ряд из 8 точек: среднее 67.975, средний скользящий размах 0.757, пределы карты отдельных значений 65.961 ... 69.989 (NIST/SEMATECH e-Handbook, "6.3.2.2. Individuals Control Charts", https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm). Окно B = 61.7 ниже нижнего предела. 8 точек - учебный минимум.
