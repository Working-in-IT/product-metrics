# render_system.py

Проверяет файл системы метрик ([формат v1](../shared/references/FORMAT.md)) и рисует его как Mermaid flowchart. Нужен Python 3 и PyYAML (`python3 -m pip install pyyaml`). Без PyYAML скрипт печатает это сообщение и завершается с кодом 2.

## Запуск

```
python3 scripts/render_system.py <METRICS_SYSTEM.md> [--out FILE] [--force]
```

- Диаграмма идёт в stdout, замечания и итог - в stderr.
- `--out FILE` пишет диаграмму в файл; для `.md` оборачивает её в блок ```` ```mermaid ````.
- При ошибках проверки диаграмма не строится; `--force` строит её всё равно.
- Код выхода: 0 - ошибок нет; 1 - есть ошибки проверки; 2 - файл не прочитан или нет PyYAML.

## Что проверяет

| Уровень | Проверка |
|---|---|
| Ошибка | Шапка есть и разбирается; `schema_version` равен 1; есть `system_id`, `product_ids`, `status`, `goals`, `relations` |
| Ошибка | Цель: `id` уникален, `metrics` непуст; метрика: ключ вида `product_id.metric_name`, без повтора, `definition_version` - положительное целое, `role` из четырёх |
| Ошибка | Связь: все семь полей; `type` из трёх; `goal_id` существует; `from` и `to` есть в `metrics` этой цели и различаются; `basis` не пуст |
| Ошибка | `status` допустим для типа: `defined`; `proposed`/`agreed`; `untested`/`supported`/`rejected` |
| Ошибка | `evidence` - список непустых строк; для `agreed`, `supported`, `rejected` не пуст |
| Ошибка | В графе `calculated_from` нет циклов |
| Предупреждение | Нет `primary` в цели; пустое `rationale`; повтор связи; в `calculated_from` нет `=` в `basis`; `supported` без `ступень: 5` или `ступень: 6` в `basis` |
| Предупреждение | Подозрение на обратное направление: `to` у `guarded_by` не `guardrail`; `from` у `guarded_by` - `guardrail`; `hypothesized_driver` идёт от `primary` к `driver` |

Рисунок: подграф на цель; узел - ключ, версия, роль; `calculated_from` - толстая стрелка «считается из»; `guarded_by` - пунктир «guardrail»; `hypothesized_driver` - пунктир «гипотеза: <status>» с цветом по статусу. Стрелки идут как в файле: от `from` к `to`.

## Результат на учебных данных

Beacon, [`METRICS_SYSTEM.md`](../shared/examples/products/beacon/METRICS_SYSTEM.md), Python 3.14.4, PyYAML 6.0.3:

- Итог: ошибок 0, предупреждений 0; код выхода 0.
- Диаграмма: 1 подграф, 5 узлов, 6 рёбер (3 `calculated_from`, 2 `guarded_by`, 1 `hypothesized_driver` со статусом `untested`).
- `--out file.md` пишет блок `mermaid`.

Негативный файл с намеренными дефектами (цикл `a -> b -> a`, ключ вне цели, `supported` без `evidence`, `evidence` не список, чужой статус, неизвестный `type`, нулевая версия) при разовой проверке дал 7 ошибок и 3 предупреждения, код выхода 1; файл в комплект не входит, результат не воспроизводится из этого дерева. Без PyYAML код 2. Отсутствующий файл - код 2.

## Чего не доказывает

- Арифметику формул: `basis` читается как текст; сходимость чисел проверяют вручную.
- Что связь верна по смыслу: цикл и ключи проверены, механизм и направление нет; эвристики направления только предупреждают.
- Что `evidence` существует: проверяется непустота списка, не наличие и не содержание ссылок.
- Что карточки метрик существуют и версии актуальны: скрипт читает одну систему, каталог не открывает.
- Что диаграмму принимает Mermaid-рендерер: синтаксис собран по документации, отрисовка в этом прогоне не выполнялась.
