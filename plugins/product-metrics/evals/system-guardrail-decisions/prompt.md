Составь план A/B-теста с двумя защитами. Сравни два правила решения. Первое — остановить релиз при обнаруженном ухудшении по любой защите; у каждой фактический уровень ложных срабатываний 5%. Второе — разрешить релиз только при показанном неухудшении обеих защит; для каждой согласован положительный допуск и мощность 80% при истинном нулевом эффекте. Какова вероятность блокировки только по защитам для безопасного изменения при независимых проверках? А если второй тест полностью дублирует первый, на тех же данных? Что можно утверждать для отдельного проекта, если его допуски ещё не согласованы?
