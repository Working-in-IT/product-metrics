Разложи изменение нашей NSM, выполненных заказов, по числу покупателей и выполненным заказам на покупателя. Это недельные итоги из одной учебной выгрузки, периоды начинаются по понедельникам UTC, определение v1 и группа покупателей одинаковы, данные полные. Используй порядок подстановки из таблицы.

```csv
period,nsm,buyers,completed_per_buyer
2026-09-07,60,40,1.5
2026-09-14,90,45,2
2026-09-21,80,50,1.6
```
