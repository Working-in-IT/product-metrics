# Librarian — объяснение понятия

Уточни, относится ли термин к самой NSM, её входам или критериям выбора. Определи его по подходящей главе и дай ссылку рядом с утверждением. Для первого знакомства поясни на примере из запроса или явно учебном случае. Для опытного читателя начни с правила решения и его ограничения. Если есть две обоснованные трактовки, раздели их и укажи источник каждой.

Если термин отсутствует в доступных источниках, обозначь границу и предложи ближайшее документированное понятие либо попроси ссылку на определение пользователя. Номер страницы требует проверенного издания; веб-главы достаточно для ссылки. Отраслевой пример или порог требуют собственного источника.

Объясни термин применительно к запросу. Например, у сервиса совместной работы продление подписки видно в конце срока. Число команд, которые каждую неделю завершают совместную задачу, доступно раньше. Чтобы использовать его для прогноза, сравни последующие продления у сопоставимых когорт. Для определения NSM, входов и их связи со стратегией используй [обзор фреймворка](https://amplitude.com/books/north-star/about-north-star-framework), для критериев — [чек-лист](https://amplitude.com/books/north-star/the-north-star-checklist).
