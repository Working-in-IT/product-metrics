# Подготовить каталог метрик

Отвечай на языке запроса: английский запрос получает английский ответ, термины формата остаются как есть.

Создай место для знаний организации вне установленного плагина. Общие шаблоны находятся в [shared](../../shared/README.md); это ресурсы плагина, не каталог пользователя.

## Размещение

Возьми рабочую папку и продукты из запроса. При отсутствии указанного места используй `metrics/` текущего пользовательского проекта. Не создавай рабочий каталог внутри установленного плагина или его кэша. Если текущая папка - сам плагин, запроси место для рабочего каталога. Если подходят несколько существующих профилей, уточни нужный или покажи кандидатов.

Прочитай существующий `CATALOG.md`, если он есть. Узко проверь, нет ли уже реестра или спецификаций в указанных пользователем местах. Сохрани известные пути и коды продуктов; повторный запуск дополняет существующее, а не обнуляет файлы.

## Создание

Используй [профиль](../../shared/templates/CATALOG.md) и [реестр](../../shared/templates/INDEX.md). Зафиксируй базу относительных путей, продукты и их устойчивые коды, пути карточек, систем, истории, предложений и журнала. Если старые спецификации известны, включи маршрут к ним. Не объявляй их отсутствие без проверки.

Создай журнал при отсутствии; добавь запись о настройке, источниках решения и нерешённых вопросах. Неизвестного владельца согласования обозначь явно - это не мешает создать черновой каталог. Не копируй учебные карточки в рабочий реестр. Массовый перенос старых определений выполняй только в рамках отдельного поручения на перенос.

Проверь, что реестр открывается из профиля, пути находятся в выбранном проекте и существующие записи сохранены. Если пользователь просит постоянную маршрутизацию агента, добавь короткую ссылку на `CATALOG.md` в принятый им файл инструкций проекта, сохранив остальные инструкции.

## Режим «без каталога»

Каталог для ответа не обязателен. Если его нет или пользователь не просит настройку, любой скилл плагина отвечает по методологии ([PRINCIPLES](../../shared/references/PRINCIPLES.md), R-08), не создаёт файлов и в конце даёт одну строку с предложением сохранить результат (карточка, система или записка). Настройку по этому шагу запускай только по согласию пользователя.

## Результат

Покажи путь к профилю и реестру, перечисли пробелы и дай один запрос для создания первой карточки через `metric-catalog`. Подключение данных и публикация каталога не входят в настройку сами по себе.
